# Available Data

LSEG Workspace is a financial data and analytics platform provided by the London Stock Exchange Group (formerly Refinitiv Eikon / Thomson Reuters Eikon). It offers real-time and historical data on equities, fixed income, commodities, foreign exchange, and more, along with news, analytics, and screening tools.

!!! info "Work in Progress"
    We are currently working on detailed documentation for the data available through LSEG Workspace. In the coming weeks, more and more guidance will be added to this page. For questions regarding access, use, and data availability, please contact **[financedata.use@uu.nl](mailto:financedata.use@uu.nl)**.
