# Charting

Charting section of LSEG provides the following data:

- **Chart** — A general‑purpose charting interface that can plot any time‑series LSEG provides, prices, returns, volumes, indices, FX, yields, macro indicators, ESG scores, supporting multiple series overlays, transformations (log, returns, spreads, rolling stats), and event markers (earnings dates, policy decisions).
- **Datastream Chart** — A charting mode built specifically on the Datastream time‑series database, giving access to its rich macro, financial, and cross‑asset histories: you select Datastream mnemonics/series, and LSEG returns long‑run data with in‑chart transformations, comparisons, and export options.
- **Chartbook** — A library of pre‑configured charts created from LSEG data, such as standard macro dashboards, market‑performance charts, factor charts, and ESG or thematic “packs”, where each chart is tied to underlying LSEG/Datastream series that you can open, modify, or export for your own analysis.
